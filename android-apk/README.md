# كشف — نسخة Android (APK)

هذا المجلد يحتوي على مشروع غلاف Android (WebView) لتطبيق **كشف**، ويُبنى بالكامل على Termux بدون Android Studio.

## الملف الجاهز

```
/data/data/com.termux/files/home/kashf3/kashf.apk
```

- **اسم الحزمة:** `com.kashf.app`
- **الإصدار:** 1.1.0 (versionCode 2)
- **الحجم:** حوالي 204 كيلوبايت
- **يعمل بدون إنترنت:** كل ملفات الموقع مضمّنة داخل الـ APK
- **الحد الأدنى:** Android 5.0 (API 21)
- **المستهدف:** Android 10 (API 29) — يسمح بالتثبيت اليدوي على الإصدارات الحديثة

## التثبيت

1. انقل `kashf.apk` إلى الهاتف أو افتحه مباشرة من Termux:
   ```bash
   termux-open ~/kashf3/kashf.apk
   ```
2. اسمح لـ Termux أو مدير الملفات بتثبيت التطبيقات من مصادر غير معروفة عند الطلب.
3. ثبّت التطبيق وافتحه.

## كيف يعمل

- يعرض الموقع من أصول داخلية عبر أصل آمن:
  `https://appassets.androidplatform.net/assets/www/index.html`
- كل طلب يُقرأ من `assets/www` داخل الـ APK، ولا يوجد اتصال بالشبكة.
- `localStorage` (قاعدة بيانات كشف `kashf_db_v1`) محفوظ داخل التطبيق.
- زر الرجوع في Android يتنقل داخل صفحات التطبيق.
- رفع الشعار يفتح منتقي الملفات في Android.
- تصدير النسخ الاحتياطي وCSV يفتح نافذة "حفظ باسم" الأصلية.
- الطباعة تفتح خدمة الطباعة في Android، ومنها **حفظ كـ PDF**.

## إعادة البناء

المتطلبات (مرة واحدة):

```bash
pkg install openjdk-17 aapt2 apksigner d8 python-pillow
```

ثم:

```bash
cd ~/kashf3/android-apk
bash build.sh
```

الناتج: `~/kashf3/kashf.apk`.

## التوقيع والتحديثات

- الملف `android-apk/kashf.keystore` هو مفتاح التوقيع.
- **احتفظ به**؛ أي تحديث مستقبلي يجب أن يُوقّع بنفس المفتاح حتى يقبل Android التحديث فوق النسخة القديمة.
- كلمة مرور الـ keystore والـ key: `kashf2026` (نسخة محلية للاستخدام الشخصي).

## ملاحظات

- التطبيق غلاف WebView وليس تطبيقاً أصلياً؛ هذا مقصود للحفاظ على نفس واجهة الويب والعمل offline-first.
- لا توجد صلاحية إنترنت في الـ manifest.
- حذف التطبيق يحذف بياناته المحلية؛ صدّر نسخة احتياطية من الإعدادات أولاً.
- التقرير `SIMULATED_REVIEW_REPORT.md` في جذر المشروع يوضح حدود المراجعة والاختبارات.
